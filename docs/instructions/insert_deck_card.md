# insert_deck_card

从牌定义创建一张牌并插入指定玩家的牌堆。

## 字段

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `player` | `player_id` | 牌堆所属玩家。 |
| `definition` | `definition_id<card_definition>` | 新牌的定义。 |
| `position` | `std::int32_t` | 插入位置；非负数从牌堆底部开始计数，负数从牌堆顶部开始计数；默认为 `-1`，即插入牌堆顶。 |

## 执行

除执行器维护的公共 `stage_t` 后缀外，本命令不要求额外栈输入，也不创建临时 frame。按 `position` 指定的位置将新牌插入牌堆。

## 注意

- 牌堆底部插入位置为 `0`，牌堆顶部插入位置为 `-1`。若当前牌堆大小为 N，则合法的底部锚点范围为 `[0, N]`，合法的顶部锚点范围为 `[-1, -N - 1]`。
- 本命令不消耗随机数。需要随机位置时，由生成本命令的一方先把随机数转换成具体 `position`。
- `card_state` 目前为空类型，暂不作为本命令字段暴露；创建牌时使用默认状态。
- `deck_card_id` 指向稳定槽位。插入只在槽位池尾部创建新牌，并在牌堆顺序中插入该槽位的索引，因此不会改变 cleanup 前已有牌实体的 ID；command 不携带该 ID 作为延迟目标。
- 插入牌堆不广播事件。牌进入牌堆后仍会参与后续广播。

## 形式化语义

1. 将 `position` 转换为牌堆顺序中的插入 index。
2. 使用 `definition` 和默认 `card_state{}` 创建牌并插入所选位置。
