# shuffle_deck

随机重排指定玩家的整个牌堆。

## 字段

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `player` | `player_id` | 需要洗牌的玩家。 |

## 栈 ABI

本指令不要求特定栈顶布局，也不读写 executor stack。

## 执行

指令对牌堆逻辑顺序执行 Fisher-Yates 洗牌。牌堆中有 N 张牌时按 N、N - 1 直到 2 的顺序各消费一个 `std::uint32_t` 随机值，共消费 N - 1 个；空牌堆和单张牌堆不消费随机值。

每个随机值通过高位乘法映射到当前未固定区间，再交换两个牌堆顺序项。洗牌只改变牌堆顺序，不移动 `card_data` 槽位，也不改变任何仍存活的 `deck_card_id`。

本指令不广播事件。洗牌完成后进入下一条固定指令。
