# replace_cards

替换若干张手牌。

## 字段

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `player` | `player_id` | 执行替换的玩家。 |

## 执行

首次进入本命令不要求特定栈顶布局。本命令会先压入并暴露输入槽：

```cpp
stack.top<selector, stage_t>();
```

`stage_t` 是物理栈顶，`selector` 是它前面的输入槽。外层填写该 selector 后继续执行。本命令假定 selector 已经填写完毕且合法。

本命令弹出 selector frame，栈顶恢复为进入本命令前的布局。随后将选中的手牌逐张随机插回牌库，再从牌库顶部向下选取等量牌加入手牌。选取时优先排除与任一被替换牌同名的牌。然后，加入手牌的牌按照加入顺序，依次推进 [`card_drawn`](../events/card_drawn.md) 广播。广播期间会临时压入本次抽到的 `hand_card_id[]`、当前游标和 `stage_t`；彻底完成时恢复入口栈形状。

## 注意

- 当前实际存在的手牌按加入手牌的顺序从 1 开始编号，第 `i` 张手牌对应选择 bitset 从低位到高位的第 `i` 位。
- 全零 bitset 表示替换零张牌。
- 本命令用于单个玩家的替换流程；双方同时开局替换通常使用 [`replace_cards_both`](replace_cards_both.md)，且该同步流程内不广播 `card_drawn`。
- 若牌库中与所有被替换牌均不同名的牌数量足够，则不会抽到与被替换牌同名的牌；否则按牌库顺序补足所需的同名牌。
- 广播第一个 `card_drawn` 前，本次选中的牌都已经插回牌库，替换得到的牌也都已经进入手牌。
- 所有 `card_drawn` 的响应者列表均在本命令执行时按替换完成后的 table 生成。前一个通知新创建的实体不响应本批次后续通知。

## 形式化语义

1. 压入 `selector, stage_t` 输入 frame 并挂起，要求恢复时 selector 的 `player` 等于本命令的 `player`。
2. 记 selector 中的 bitset 为 `M`，并弹出该 selector。
3. 按手牌加入顺序遍历当前实际存在的手牌，根据 `M` 取得所有被选择的手牌，依次组成序列 `S`。
4. 令 `X = |S|`，令 `B` 为 `S` 中所有牌的名称组成的集合。
5. 对于每个 `s` ∈ `S`，从手牌中移除 `s`，在当前牌库的所有可插入位置中等概率选择一个位置，并将 `s` 插入该位置。
6. 记当前牌库中名称不属于 `B` 的牌数为 `Y`。
7. 令 `C` 为空序列。
8. 从牌库顶部向底部依次检查牌，直至 `|C| = X`：
   - 若牌的名称不属于 `B`，则将其从牌库移除并加入手牌，再将其 `hand_card_id` 追加到 `C`；
   - 若牌的名称属于 `B`、`X > Y`，且此前加入 `C` 且名称属于 `B` 的牌数量小于 `X - Y`，则将其从牌库移除并加入手牌，再将其 `hand_card_id` 追加到 `C`；
   - 否则继续检查下一张牌。
9. 对于每个 `c` ∈ `C`，依次推进 `card_drawn { card = c }` 广播。
