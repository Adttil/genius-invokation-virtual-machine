# givm::definition_library::tag_count

定义于头文件 `<givm/runtime.hpp>`

```cpp
std::size_t tag_count() const noexcept;
```

取得定义库中不同标签的数量。

## 返回值

本定义库中的标签总数。同名标签只计一次。
